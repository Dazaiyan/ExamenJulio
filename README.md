# Router Flyer

Minijuego web para un portal cautivo de demostración hecho con Flask, HTML, CSS y JavaScript.

## Ejecutar

```bash
pip install -r requirements.txt
python app.py
```

Abre `http://127.0.0.1:5000/`.

## Flujo

- Si el router pierde la partida, el juego se reinicia solo.
- Si alcanza la meta, redirige a `/portal`, una pantalla sencilla de portal cautivo.
